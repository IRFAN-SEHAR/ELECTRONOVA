# Electronics Storefront — React + Vite

Responsive electronics catalogue starter with product categories, search, product cards, enquiry links to the contact section, store details and mobile navigation.

## Before publishing
Edit `src/config.js` and replace ALL sample content with verified information: store name, description, phone, email, location, hours, actual product/model names, prices in PKR, specifications, stock status and product images. The current product names, prices and some images are examples. Do not publish placeholder prices or claims as real inventory. Add warranty, return, delivery or payment policies only if the store genuinely offers them.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
Production output is in `dist`.

## Netlify / Vercel
Framework: Vite | Build command: `npm run build` | Publish/output directory: `dist` | Root directory: blank if `package.json` is in the repository root.

## Scope and ad review
This is a product catalogue/enquiry storefront, not a transactional e-commerce system. It does not process payments, manage inventory or place orders. It intentionally has no WhatsApp/social links or automatic redirects. This does not guarantee Snapchat approval; the live page must accurately match the ad and comply with current ad policies.
